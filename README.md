# 🇪🇸 Spanish Translation — Road to Vostok

**Traducción completa al español para Road to Vostok (Early Access).**  
Complete Spanish localization for Road to Vostok. No original game files are replaced — the mod injects translations at runtime from a `.json` file via the Godot Mod Loader.

---

| Contenido | Estado |

> Traducción elaborada sobre la versión Early Access **[0.1.1.3]**. Se actualizará conforme el juego reciba nuevas builds.

## Requisitos / Requirements

- [Metro Mod Loader](https://modworkshop.net/mod/55623) — necesario para cargar el mod
- [Mod Configuration Menu (MCM)](https://modworkshop.net/mod/56029) — necesario para el toggle en el menú de opciones

---

## Instalación / Installation

1. Instala **Metro Mod Loader** siguiendo las instrucciones de su página.
2. Instala **Mod Configuration Menu**.
3. Descarga `spanish-rtv.vmz` y colócalo en:
   ```
   SteamLibrary\steamapps\common\Road to Vostok\mods\
   ```
4. Lanza el juego normalmente. La traducción se aplica automáticamente.

> ⚠️ No descomprimas el archivo `.vmz`. Déjalo tal como está.

---

## Características / Features

- Traducción al vuelo desde `.json`, sin reemplazar archivos del juego
- Toggle **activar / desactivar** la traducción desde el Mod Configuration Menu sin reiniciar
- Compatible con otros mods de la comunidad
